# Урок английского на доске Holst по названию темы

Вход — одна строка с темой («Travelling, conditionals 0,1,2,3 and mixed»). Выход — новая доска
Holst с уроком из пяти секций слева направо и ссылка на неё. Урок должен выглядеть так, будто его
собрал сам преподаватель, — его стиль описан в `references/teacher-style.md`, и это главный
ориентир по дизайну и тону.

## Правила

Стоят первыми: после сжатия контекста от скилла остаётся начало.

- **Методика важнее красоты.** Каждый пример грамматики — на лексике темы; каждое предложение
  упражнения однозначно (есть маркер времени); ключ сверен с заданиями. Список проверок —
  `references/lesson-blueprint.md`, раздел 3. Ошибку в грамматике преподаватель увидит первой.
- **Мемы рисуйте сами** (HTML → PNG, `references/meme-formats.md`), чужие картинки из интернета не
  качайте. Каждый мем объясняет одно правило или одну ошибку.
- **Пишите в своё пространство.** В чужом пространстве, где пользователь гость, Holst не даёт
  ни читать, ни писать (`PERMISSION_DENIED`). Делайте новую доску в своём и скажите, как перенести
  (экспорт .holst → импорт).
- **Не перегружайте доску.** Преподаватель рисует пером поверх урока — вокруг упражнений нужен
  воздух. Никаких таблиц с тёмной шапкой, диаграмм и канбанов.
- **Текст с полями — через `panel()`**, а не Shape: у Shape текст липнет к рамке.
- **Проверяйте глазами.** После каждой секции — скриншот и просмотр; мемы — открыть каждый PNG.
- Всё пользователю — по-русски; содержимое урока — английский с короткими русскими пояснениями.
- В конце — одна ссылка `resultLink` на доску (кликабельной markdown-ссылкой, без бэктиков).

## Порядок работы

### 0. Подключиться к Holst

Есть инструменты `mcp__holst__*` — работайте ими. Нет или `ECONNREFUSED` — запустите приложение
(macOS: `open -a Holst`) и работайте через `scripts/holst-mcp.mjs` (тот же MCP по HTTP, нужен
Node 18+). Подробно, для macOS и Windows, включая Codex, — `references/holst-notes.md`, раздел
«Подключение». Все скрипты скилла — Node, запускаются одинаково на обеих ОС.

Перед первым `use_holst` прочитайте гайды Holst целиком: `holst-use-api.d.ts`,
`holst-use-workflow`, `workshop-templates`, `native-visual-system`, `assets`
(через `get_guide` или `holst-mcp.mjs guide <topic> <файл>`). API меняется — не полагайтесь на
память.

### 1. Стиль (только если просят «в стиле …» и дали новую выгрузку)

Стиль текущего преподавателя уже снят — `references/teacher-style.md`. Если дали другую доску:
распакуйте `.holst` (это zip) и запустите
`node scripts/inspect-holst-export.mjs <папка> --since <полгода назад> --texts texts.txt`,
прочитайте тексты последних уроков, посмотрите 5–10 картинок из последних уроков. Обновите
`teacher-style.md` и палитру в `scripts/lib.js`.

### 2. Содержание урока — сначала текстом

По `references/lesson-blueprint.md` разберите тему (лексика / грамматика / обе), определите
уровень и напишите всё содержимое: скороговорку, вопросы, группы слов с транскрипцией, постеры
(формула, When?, 3 примера, ⚠️ ошибка), сюжеты мемов, упражнения, ключ, домашку. Прогоните
проверки из раздела 3. Только потом рисуйте — переделывать текст на доске дороже.

### 3. Мемы

По одному на правило + один «Your turn» для говорения. Форматы под грамматику — таблица в
`references/meme-formats.md`; образцы — `assets/memes/travelling-conditionals/`. Рендер —
`scripts/render-memes.mjs`, проверить каждый PNG, загрузить на доску
(`holst-mcp.mjs upload` или `upload_assets` + POST). Сетка warm-up тоже загружается:
`assets/warmup-how-are-you-today.png`.

### 4. Сборка доски

`create_board` с именем «<Тема> <эмодзи>» → корневой Frame (`SECTION.root`) → секции слева
направо, по одной-две на вызов `use_holst`:

| Секция | Хелпер / размеры |
|---|---|
| титул «Welcome to the English class ✈️» + тема | `T(..., 120, {color:BURG})` на корне |
| ☕ Warm-up | мем-сетка 1000 px слева; скороговорка, Let's talk, Today's route — справа панелями |
| 🧳 Полезные слова | 2×2 `panel()` по 1040 px |
| 🧠 Грамматика | колонки 1000 px: `pill` → подзаголовок → `formula` → When? → Examples (`hl`) → ⚠️ `panel` → мем внизу |
| ✍️ Practice | 3–4 упражнения панелями в две колонки |
| 💬 Speaking & 🏠 Homework | вопросы, игра, мем «Your turn», домашка, серый 🔑 Answer key |

В каждый вызов приклеивайте `scripts/lib.js` (`holst-mcp.mjs use <boardId> <file.js> --lib`,
либо вставьте текст файла в начало `code`): там шрифт, палитра, `T`, `hl`, `panel`, `pill`,
`formula`, `section`, `fit`, `nextX`. Возвращайте id корня и секций и берите их в следующем вызове
через `holst.getNodeById`. Грамматику: сначала одна колонка + скриншот, потом остальные.
В конце каждой секции — `fit(frame)`, в конце урока — размер корня по секциям.

### 5. Проверка и ответ

Обзорный скриншот корня (`scale` ≥ 0.25) и крупно 1–2 секции. Ищите: наезды, обрезанный текст,
свёрнутые плашки, пустые низы секций, мемы не на одной линии. Правьте точечно.

Ответ пользователю (по-русски): ссылка на доску, что в каждой секции в 1–2 строках, что
сознательно сделано иначе (новая доска вместо чужого пространства, мемы нарисованы из эмодзи), что
не проверено (вид в самом приложении).

## Файлы скилла

- `references/teacher-style.md` — стиль преподавателя: шрифт, цвета, порядок урока, юмор.
- `references/lesson-blueprint.md` — от темы к содержанию, секции, проверки, готовый пример.
- `references/meme-formats.md` — форматы мемов под грамматику, как рендерить.
- `references/holst-notes.md` — подключение к Holst, гостевые пространства, грабли.
- `scripts/holst-mcp.mjs` — MCP Holst по HTTP: `tools | call | guide | use | upload`.
- `scripts/lib.js` — хелперы и палитра для `use_holst`.
- `scripts/render-memes.mjs` — HTML-мемы → PNG через headless Edge/Chrome.
- `scripts/inspect-holst-export.mjs` — разбор выгрузки .holst: шрифты, цвета, тексты, картинки.
- `assets/memes/` — `base.css` и шесть мемов урока Travelling & Conditionals (html + png).
- `assets/warmup-how-are-you-today.png` — мем-сетка настроения для warm-up.
- `install.sh` (macOS/Linux), `install.bat` + `install.ps1` (Windows), `УСТАНОВКА.md` — установка
  для Claude Code и Codex; к работе над уроком не нужны.
