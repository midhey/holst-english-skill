# Holst: как подключиться и на чём спотыкались

## Подключение

Holst — десктопное приложение; его MCP-сервер слушает `http://127.0.0.1:47641/mcp` только пока
приложение запущено и вы в нём залогинены. Скрипты скилла работают на macOS и Windows.

1. **MCP-инструменты `mcp__holst__*` есть в сессии** — пользуйтесь ими напрямую.
2. **Их нет или ECONNREFUSED** (Codex без настроенного holst; агент поднялся раньше приложения):
   - запустите приложение и подождите несколько секунд, пока откроется порт:

     | | macOS | Windows |
     |---|---|---|
     | запуск | `open -a Holst` | `%LOCALAPPDATA%\Programs\holst-desktop-app\Holst.exe` |
     | порт слушается? | `lsof -nP -iTCP:47641 -sTCP:LISTEN` | `Get-NetTCPConnection -LocalPort 47641 -State Listen` |

   - порт 47641 проверен на Windows. Если на Mac он другой — найдите его
     (`lsof -nP -iTCP -sTCP:LISTEN | grep -i holst`) и задайте `HOLST_MCP_URL=http://127.0.0.1:<порт>/mcp`;
   - сессия агента сама не переподключится — работайте через `scripts/holst-mcp.mjs`, это тот же
     MCP по HTTP. Пользователь может переподключить сервер через `/mcp`, но ждать этого не нужно.
3. Node 18+ (нужен глобальный `fetch`). Проверка: `node -v`. На Mac без Node — `brew install node`.
   На Windows-машине автора `node` в PATH — 14; там берите `%NVM_HOME%\v22.22.2\node.exe` полным путём.

Для Codex можно один раз прописать сервер в `~/.codex/config.toml` (путь одинаковый на обеих ОС):

```toml
[mcp_servers.holst]
url = "http://127.0.0.1:47641/mcp"
```

## Куда класть урок

- **Чужое пространство, где вы гость** — `PERMISSION_DENIED: not available to guests`. Читать доску
  нельзя, писать тоже. Значит, урок собирается в своём пространстве (`list_workspaces` → обычно
  «Тестовое пространство»), а преподаватель переносит его к себе через экспорт `.holst` → импорт.
- Новый урок = **новая доска** (`create_board`, имя «<Тема> ✈️»), если не попросили дописать в
  существующую. В существующую — справа от последнего острова, `nextX(root)` по корневым кадрам.
- Стиль преподавателя, если вы гость, берётся из выгрузки: пользователь экспортирует доску в
  `.holst` (меню доски → Экспорт; в окне «Экспорт доски» PNG/PDF — это не то, нужен именно .holst),
  дальше `scripts/inspect-holst-export.mjs`.

## Грабли, на которые уже наступили

| Симптом | Причина | Что делать |
|---|---|---|
| Текст в карточке прилип к рамке | у Shape нет внутренних полей | `panel()` — Frame + Text с отступом 40 |
| Плашка-заголовок свернулась в узкий столбик в 3 строки | Shape без ширины | `pill(..., w)` с явной шириной, `fixedSize:true` |
| Эмодзи на скриншоте — квадратики □ | первый рендер headless-сессии ещё без шрифта эмодзи | на следующих скриншотах появляются; в приложении рисуются всегда. Не убирайте эмодзи из-за этого |
| `RangeError: screenshot.scale must be between 0.25 and 2` | широкий корень снимали с 0.22 | минимум 0.25; для обзора всей доски — `root.screenshot({scale:0.25})` |
| Огромные пустые низы у секций | всем секциям выставили одну высоту | `fit(frame)` каждой секции по своему содержимому |
| Высота Frame не выросла после добавления детей | Frame не растёт сам | `fit()` в конце каждого вызова |
| Chrome headless на Windows висит и не пишет PNG | `--headless=new` + профиль | `render-memes.mjs` берёт на Windows сначала Edge (~3 с на мем); на Mac — сначала Chrome |
| `upload_assets` вернул меньше URL, чем файлов | читали URL построчно и потеряли последний без перевода строки | `holst-mcp.mjs upload` сам бьёт по 10 |
| Заливка панели прочиталась не тем цветом | в `fill` Frame вернулся токен/другой HEX | сравнивать не по цвету, а держать id нужных узлов |

## Порядок вызовов `use_holst` (5–7 штук на урок)

1. корень + титул + Warm-up (скриншот секции);
2. Полезные слова (скриншот);
3. грамматика: сначала **одна** колонка-постер и скриншот, потом остальные одним вызовом;
4. Practice;
5. Speaking + Homework + Answer key, `fit()` всех секций, размер корня;
6. обзорный скриншот корня + скриншоты 1–2 секций крупнее; правки точечно; `resultLink`.

Id корня и секций возвращайте из каждого вызова и подставляйте в следующий
(`holst.getNodeById(id)`) — handles между вызовами не живут.
